# Changelog

## 0.1.0

- Standalone Git-installable Pi package; no replacement of personal extensions.
- GTK4/Wayland visual-novel desktop, with normal-window fallback.
- Neutral default and optional Shadow / Commander character packs.
- Versioned per-instance transport, explicit pins and addressed whispers.
- Self-contained persona/footer handling and optional character delegate tool.
- Public assistant dialogue, blinking, reply-triggered speaking, speaker foreground.
- Doctor command, isolated installation/removal tests, fake child-runner tests,
  multiple-instance and stale-event tests, and GTK regression.

Local Linux only. No remote connection, TTS or phoneme lip sync in this release.
